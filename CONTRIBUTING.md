# Contributing to Travel Planning Engine

We love your input! We want to make contributing to this project as easy and transparent as possible.

## Development Process

1. Fork the repo and create your branch from `main`
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Make your changes
4. Write or update tests as needed
5. Ensure the code lints and passes tests
6. Commit your changes: `git commit -am 'Add your feature'`
7. Push to the branch: `git push origin feature/your-feature`
8. Open a Pull Request

## Pull Request Process

1. Update the README.md with details of changes if applicable
2. Update version numbers following [SemVer](https://semver.org/)
3. Link any related issues in the PR description
4. Ensure all tests pass

## Code Style

- Use consistent indentation (2 spaces)
- Follow ESLint configuration
- Write descriptive commit messages
- Add comments for complex logic

## Reporting Bugs

- Use the Issues tab to report bugs
- Include a clear description
- Provide steps to reproduce
- Include expected and actual behavior

## Feature Requests

- Use the Issues tab with label `enhancement`
- Clearly describe the use case
- Provide examples if possible
